The `fineract-core` module is the platform's shared infrastructure library. It provides every cross-cutting subsystem — data routing, tenant context, business dates, global configuration, cache management, event abstractions, security utilities, and bulk-import SPIs — that all other modules (fineract-provider, fineract-loan, fineract-savings, …) import. Nothing in fineract-core depends on any domain module; the dependency arrow always points inward.

<Info>
`fineract-core` compiles to a plain JAR, not an executable. It is assembled into a runnable application only by **fineract-provider**. Keep infrastructure-only code here and domain-specific code in domain modules.
</Info>

## Module boundary: what belongs here vs fineract-provider

| Criterion | fineract-core | fineract-provider |
|---|---|---|
| Shared by ≥2 domain modules | ✅ | ❌ |
| Spring Boot `@SpringBootApplication` entry point | ❌ | ✅ |
| Jersey/JAX-RS `ResourceConfig` registration | ❌ | ✅ |
| HikariCP connection pool wiring | ✅ (factory helpers) | ✅ (final beans) |
| Liquibase runner | ❌ | ✅ |
| Domain entity (Loan, Savings, Client…) | ❌ | ✅ |
| Business event domain types (e.g. `LoanCreatedBusinessEvent`) | ❌ | ✅ |

## Key abstractions

### `ThreadLocalContextUtil`
**File:** `infrastructure/core/service/ThreadLocalContextUtil.java`

Carries five thread-local variables for the duration of a single request:

```java
ThreadLocal<FineractPlatformTenant>              tenantContext
ThreadLocal<String>                               contextHolder       // "tenants" or per-tenant identifier
ThreadLocal<String>                               authTokenContext
ThreadLocal<HashMap<BusinessDateType, LocalDate>> businessDateContext
ThreadLocal<ActionContext>                        actionContext
```

Key static methods:
- `setTenant(FineractPlatformTenant)` — called by `TenantAwareBasicAuthenticationFilter` on every request.
- `getBusinessDate()` — delegates to `getActionContext().getBusinessDateType()`, then `getBusinessDateByType(type)`.
- `init(FineractContext)` — bulk-sets all five variables from a serialisable `FineractContext` snapshot (used when propagating context to async worker threads).
- `reset()` — must be called at the end of every request (or in `finally`) to prevent context leaks across pooled threads.

### `FineractPlatformTenant`
**File:** `infrastructure/core/domain/FineractPlatformTenant.java`

```java
@Jacksonized @Builder
public class FineractPlatformTenant implements Serializable {
    Long id;
    String tenantIdentifier;
    String name;
    String timezoneId;
    FineractPlatformTenantConnection connection;
}
```

`FineractPlatformTenantConnection` (same package) stores every HikariCP pool parameter: `schemaServer`, `schemaServerPort`, `schemaName`, `schemaUsername`, `schemaPassword`, `maxActive`, `initialSize`, read-only replicas (`readOnlySchemaServer` etc.), and `masterPasswordHash` for encrypted passwords.

### `RoutingDataSource`
**File:** `infrastructure/core/service/database/RoutingDataSource.java`

Spring-primary `DataSource` bean (`@Service("dataSource") @Primary`). On every `getConnection()` call it delegates to `RoutingDataSourceServiceFactory.determineDataSourceService().retrieveDataSource()`.

`RoutingDataSourceServiceFactory` reads `ThreadLocalContextUtil.getDataSourceContext()` to decide which service to use:
- `"tenants"` → `dataSourceForTenants` (the master `fineract_tenants` pool)
- anything else → `tomcatJdbcDataSourcePerTenantService` (per-tenant pool built by `DataSourcePerTenantServiceFactory`)

`DataSourcePerTenantServiceFactory.createNewDataSourceFor(tenant, connection)` builds a fresh HikariCP pool with validated master password, respects `fineract.tenant.config.*` overrides, and registers Micrometer metrics.

## BusinessDate subsystem

The business-date system allows operations to run against a logical date independent of wall-clock time — essential for COB (Close of Business) batch processing.

### `BusinessDateType` enum
**File:** `infrastructure/businessdate/domain/BusinessDateType.java`

| Value | id | description |
|---|---|---|
| `BUSINESS_DATE` | 1 | Regular business date (used by most operations) |
| `COB_DATE` | 2 | Close of Business date (used by COB batch) |

### `BusinessDate` entity
**File:** `infrastructure/businessdate/domain/BusinessDate.java`

JPA entity mapped to table `m_business_date`. Has a `@UniqueConstraint` on `type` so only one record per `BusinessDateType` exists per tenant.

```java
@Table(name = "m_business_date")
public class BusinessDate extends AbstractAuditableWithUTCDateTimeCustom<Long> {
    BusinessDateType type;
    LocalDate date;
    @Version Long version;  // optimistic locking
}
```

### `BusinessDateReadPlatformService`
**File:** `infrastructure/businessdate/service/BusinessDateReadPlatformService.java`

```java
public interface BusinessDateReadPlatformService {
    List<BusinessDateDTO> findAll();
    BusinessDateDTO findByType(String type);
    HashMap<BusinessDateType, LocalDate> getBusinessDates();
}
```

`getBusinessDates()` is called by `TenantAwareBasicAuthenticationFilter` at the start of every request. The resulting `HashMap<BusinessDateType, LocalDate>` is loaded into `ThreadLocalContextUtil.businessDateContext` for the lifetime of the thread.

### BusinessDate flow

<Steps>
  <Step title="Request arrives">
    `TenantAwareBasicAuthenticationFilter.doFilterInternal` reads the `Fineract-Platform-TenantId` header.
  </Step>
  <Step title="Tenant loaded">
    `TenantDetailsService.loadTenantById` queries `fineract_tenants` DB. `ThreadLocalContextUtil.setTenant` stores it.
  </Step>
  <Step title="Business dates loaded">
    `BusinessDateReadPlatformService.getBusinessDates()` queries `m_business_date` for this tenant. `ThreadLocalContextUtil.setBusinessDates` stores the map.
  </Step>
  <Step title="Domain code reads date">
    Any service calls `ThreadLocalContextUtil.getBusinessDate()` → `actionContext.getBusinessDateType()` → map lookup.
  </Step>
  <Step title="BusinessDate update">
    `BusinessDateApiResource` → `BusinessDateUpdateHandler` → `BusinessDateWritePlatformServiceImpl.updateBusinessDate` saves to `m_business_date` and fires a `BusinessDateChangedEvent`.
  </Step>
</Steps>

<Warning>
Business dates are loaded once per thread at filter time. If you spawn a new thread inside a service method you **must** call `ThreadLocalContextUtil.init(context)` with a snapshot captured before forking, or the child thread will throw `NullPointerException` on any `getBusinessDate()` call.
</Warning>

## Cache management

### `PlatformCache` entity
**File:** `infrastructure/cache/domain/PlatformCache.java` — mapped to table `c_cache`. Stores the active cache type per tenant.

### `CacheType` enum
**File:** `infrastructure/cache/domain/CacheType.java` — values: `NO_CACHE`, `SINGLE_NODE`, `MULTI_NODE`.

### `RuntimeDelegatingCacheManager`
**File:** `infrastructure/cache/service/RuntimeDelegatingCacheManager.java` — Spring `CacheManager` implementation that delegates to the cache implementation selected at runtime (none / Ehcache single-node / Hazelcast multi-node). Switches dynamically via `CacheWritePlatformService.switchToCache`.

### `CacheApiResource`
**File:** `infrastructure/cache/api/CacheApiResource.java` — JAX-RS resource at `GET/PUT /api/v1/caches`. `PUT` triggers `CacheSwitchCommandHandler` which persists the new type in `c_cache` and calls `RuntimeDelegatingCacheManager.switchToCache`.

## fineract-validation module

The `fineract-validation` module (`fineract-validation/src/main/java/org/apache/fineract/validation/`) provides Jakarta Bean Validation constraints beyond the standard set.

| Annotation | Validator | Validates |
|---|---|---|
| `@DateFormat` | `DateFormatValidator` | String is a valid `DateTimeFormatter` pattern |
| `@EnumValue` | `EnumValueValidator` | String maps to a known enum constant |
| `@LocalDate` | `LocalDateValidator` | String parses to `java.time.LocalDate` in the given format |
| `@Locale` | `LocaleValidator` | String is a known Java locale tag |

These are used on incoming API request bodies (Jackson-deserialized POJOs) via Jersey's `ValidationFeature` registered in `JerseyConfig`.

## Instance-mode filter

`FineractInstanceModeApiFilter` (`infrastructure/instancemode/filter/FineractInstanceModeApiFilter.java`) is a Spring `OncePerRequestFilter` that rejects HTTP calls that do not match the node's configured operating mode (`fineract.mode.*` properties). For example a read-only node (`readEnabled=true, writeEnabled=false`) rejects POST/PUT/DELETE requests to most endpoints. Exception paths (always allowed regardless of mode): `/v1/batches`, `/v1/instance-mode`, `/v1/jobs`, `/v1/scheduler`, `/v1/loans/catch-up`, actuator endpoints.

## Gotchas & invariants

<Accordion title="Thread-local cleanup is mandatory">
`ThreadLocalContextUtil.reset()` must be called in a `finally` block in any code that calls `setTenant`, `setBusinessDates`, etc. In servlet threads this is handled by `TenantAwareBasicAuthenticationFilter`, but manually spawned threads (e.g. `CompletableFuture.supplyAsync`) have **no** automatic cleanup and will silently retain stale tenant context if pooled.
</Accordion>

<Accordion title="Optimistic locking on BusinessDate">
`BusinessDate` has a `@Version Long version` field. Concurrent updates to the same date type will throw `ObjectOptimisticLockingFailureException`. The COB batch runner retries on these failures.
</Accordion>

<Accordion title="GlobalConfigurationProperty trapDoor flag">
Any `GlobalConfigurationProperty` with `isTrapDoor=true` cannot be changed via the API once set. Attempts throw `GlobalConfigurationException`. Seed data migrations set this for security-sensitive flags.
</Accordion>

<Accordion title="RoutingDataSource is not AbstractRoutingDataSource">
Fineract's `RoutingDataSource` extends `AbstractDataSource` (not Spring's `AbstractRoutingDataSource`). It manually delegates to `RoutingDataSourceServiceFactory` on each `getConnection()` call. This means the lookup key is the *current thread's* `ThreadLocalContextUtil.getDataSourceContext()` value, not a Spring-managed lookup key. Never swap the data source context inside an active transaction.
</Accordion>
